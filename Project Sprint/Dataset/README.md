# TrashNet Dataset

## Dataset Information

This project uses the TrashNet dataset for six-class waste image classification.

Dataset source:

https://github.com/garythung/trashnet

The dataset contains 2,527 images belonging to six waste categories:

- cardboard: 403
- glass: 501
- metal: 410
- paper: 594
- plastic: 482
- trash: 137

The images are organized into class-specific directories.

## Dataset Preparation

The raw dataset is stored locally in:

`Dataset/raw/`

The processed dataset is generated by:

`src/data/preprocess_dataset.py`

The processed dataset is divided into:

- Training: 1,765 images (70%)
- Validation: 379 images (15%)
- Testing: 383 images (15%)

The processed dataset is stored locally in:

`Dataset/processed/`

The raw and processed image files are excluded from the Git repository through `.gitignore` because of their size. The preprocessing script can recreate the processed dataset from the raw dataset.
